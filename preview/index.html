C++ / NETWORKING · 2017–PRESENT

Coroute / WebFrame++

A cross-platform web framework with a coroutine-based I/O scheduler, lock-free queues and a unified asynchronous API over IOCP, io_uring and kqueue. I’ve worked on scheduling and caching to reduce latency jitter, HTTP pipelining and asynchronous file streaming.

Benchmarks & project background

My earlier Windows and Linux benchmarks measured 750,000–1.2 million requests per second with wrk and ab. Scheduler and queue changes improved throughput by about 13% in that work. These are historical, workload-dependent results; see the project for benchmark context. The project is part of a patent application.

  • Coroutines
  • Cross-platform I/O
  • HTTP & WebSocket

C++23 / BACHELOR’S THESIS · 2026

Compile-time ORM

My bachelor’s thesis: an ORM that represents queries in the C++ type system and catches structural errors at compile time. Typed fields, joins and parameter binding connect C++ entities to SQL, with SQLite and mock database backends.

I’ve been writing C++ since December 2012. I’m still asking what happens underneath.

That question has taken me through competitive programming, systems engineering, research, and teaching. I’m drawn to the places where abstractions meet the real machine: concurrency, networking, memory, and performance.

Outside software, I’m interested in neuroscience and brain health, and in the habits that support learning and focus. I train at the gym, play football and table tennis, and listen to rock and metal.

I’ve also been involved in League of Legends eSports since 2021 as a coach, analyst and team manager, and more recently as a color commentator. Teaching, teamwork and understanding performance matter there too.

Alex Tsvetanov: engineering & research

I’m Alex Tsvetanov (Алекс Цветанов), a senior C++ engineer, researcher and educator in Sofia, Bulgaria. I work on concurrency, asynchronous I/O, distributed systems and compile-time programming.

What do I build?

Coroute / WebFrame++ explores coroutine-based web serving and cross-platform I/O. Compile-time Protobuf explores schema parsing and serialization in C++. My C++ ORM bachelor’s thesis checks query structure at compile time.

Where can I find the evidence?

See the repositories above for code and project documentation, and my publications and recorded technical talks for research context. I completed a B.Eng. in Computer and Software Engineering at the Technical University of Sofia in 2026.
